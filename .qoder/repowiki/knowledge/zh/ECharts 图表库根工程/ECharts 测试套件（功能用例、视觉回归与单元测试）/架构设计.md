本模块按测试类型划分为三个层次：
- 顶层 `test/*.html` 为浏览器可直接打开的功能演示/手工用例，通过 `test/lib/testHelper.js` 等共享库统一初始化图表、生成输入控件并支持拖拽、主题切换等调试能力；`test/data/` 集中存放 JSON/SVG/PNG 等静态数据与地图资源。
- `test/runTest/` 是视觉回归测试子系统：`cli.js` 作为命令行入口，使用 `puppeteer` 启动无头浏览器加载每个 `.html` 用例，通过 `page.exposeFunction` 暴露 `__VRT_*` 系列钩子让页面侧录制/回放鼠标动作并截图；`actions/*.json` 描述交互序列，`marks/*.json` 保存期望截图，`compareScreenshot.js` 用 `pixelmatch` + `pngjs` 计算差异图，`server.js` 通过 `serve-handler` 提供本地 HTTP 服务并在 `8866` 端口暴露不同版本的 `echarts.js`（由 `util.js` 中的 `getVersionDir` 路由），`task.js` 负责任务调度，`store.js` 持久化测试结果。
- `test/ut/` 是渲染无关的单元测试层：基于 `ts-jest` + `jest-canvas-mock` + `jsdom`，通过 `jest.config.cjs` 将 `@/*` 映射到仓库根目录以直接 import 源码，`spec/{api,component,series,data,model,scale,util}` 下按源码结构组织 `.test.ts` 断言，`core/setup.ts` 与 `core/extendExpect.ts` 提供全局 setup 与自定义 expect 匹配器。
依赖方向：`runTest/cli.js` → `util/config/task` → `puppeteer` 驱动浏览器执行 `test/*.html`；`ut` 独立于 `runTest`，两者均依赖上层 `src/` 源码产物或构建后的 `dist/echarts.js`。
