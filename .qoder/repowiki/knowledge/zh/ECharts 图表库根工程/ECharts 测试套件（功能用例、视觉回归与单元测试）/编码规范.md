- 每个被测特性对应一个独立的 `*.html` 文件，并通过 `test/lib/simpleRequire.js` 按需引入 ECharts 与 testHelper 进行初始化。
- 视觉回归用例采用“期望截图 + 实际截图 + diff”三件套模式：期望结果存放在 `runTest/marks/<case>.json`，运行时在 `runTest/actions/<case>.json` 中声明鼠标/键盘动作序列，最终由 `compareScreenshot.js` 输出 PNG/WebP 差异图。
- 用例通过 URL 查询参数（如 `__RENDERER__`、`__COARSE_POINTER__`、`__THEME__`）向运行时注入渲染配置，而非修改 HTML 源码，以便同一用例在不同渲染后端下复用。
- 单元测试按源码包结构镜像组织在 `ut/spec/{api,component,series,data,model,scale,util}` 下，文件名以 `<module>.test.ts` 命名，并通过 `tsconfig.json` 的 `paths` 以 `@/...` 别名导入源码。
- 测试辅助逻辑集中在 `test/lib/testHelper.js` 中，通过 `chart.__testHelper.*` 暴露拖拽、输入控件、状态恢复等能力，供各 HTML 用例复用。
