视觉回归测试需先在 `../build` 中 `npm install && node build.js` 构建当前版本 `dist/echarts.js`，再进入 `test/ut` 执行 `./configure` 下载上一发布版 `oldEcharts.js`，最后打开 `ut/ui.html` 或在 `runTest` 目录下 `npm start`（即 `node server.js`）启动本地服务后通过 `cli.js -t <caseName> --expected <version>` 运行；可通过 `--renderer svg|canvas`、`--use-coarse-pointer auto|true|false`、`--theme <name>`、`--threads <n>` 控制渲染与并发。
