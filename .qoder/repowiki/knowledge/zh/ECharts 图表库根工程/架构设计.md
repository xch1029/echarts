根目录作为 ECharts 包的工作区，通过 package.json 的 exports 字段将 src/（核心）、lib/（预编译图表与组件）、extension/（百度地图与数据工具）、i18n/（多语言文案）以及 ssr/client/（服务端渲染客户端）统一暴露为 npm 子路径入口；build/ 下的 Node 脚本（build.js、build-i18n.js、build-lib.js、dev-fast.js 等）按 --type 参数组合生成 dist/ 与 types/ 产物，并由 sideEffects 声明各入口副作用以便 Tree-shaking。tests/ 通过 test:visual（Puppeteer 视觉回归）与 test:ut（Jest TypeScript 单测）对 core、chart、component、extension、i18n 进行验证，husky + ESLint/TSC 在提交阶段约束全仓代码风格与类型。
