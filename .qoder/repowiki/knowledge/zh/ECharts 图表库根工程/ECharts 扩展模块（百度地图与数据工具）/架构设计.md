本模块由两个相互独立的子扩展组成，均通过 `import * as echarts` 引入核心并注册自身，不依赖彼此。
- `bmap/`：实现百度地图坐标系扩展，遵循 ECharts 组件模型——`BMapModel.ts` 通过 `extendComponentModel` 扩展 `ComponentModel`，定义 `COMPONENT_MAIN_TYPE_BMAP = 'bmap'`、默认配置 `defaultOption`（center/zoom/mapStyle/mapStyleV2/mapOptions/roam）及 `getBMap`、`setCenterAndZoom`、`centerOrZoomChanged` 等方法；`BMapCoordSys.ts` 与 `BMapView.ts` 分别实现坐标系与视图渲染；入口 `bmap.ts` 作为插件装配点，依次 import 上述三文件以触发副作用注册，并通过 `echarts.registerAction({type:'bmapRoam', ...})` 响应地图拖拽缩放事件，最终导出 `version = '1.0.0'`。
- `dataTool/`：纯函数式数据处理工具集，无副作用。`index.ts` 聚合导出 `gexf.parse`（基于 DOMParser 解析 GEXF XML 为 nodes/links）和 `prepareBoxplotData`（按 IQR 计算四分位数、异常值与 boxData），并在运行时将 `version`、`gexf`、`prepareBoxplotData` 挂载到 `echarts.dataTool` 命名空间以兼容旧版 ECharts。
- 构建层面，`bmap/tsconfig.json` 将 `echarts` 路径映射到仓库根目录，target 设为 ES3 以兼容老环境；每个子目录自带 `.eslintrc.yaml` 独立 lint 配置。
